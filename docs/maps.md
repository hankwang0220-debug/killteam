## 4. 轉錄成遊戲地圖時的做法

1. 以原圖網格逐格讀出每件地形的外框（單位：吋，原點在左上角）。
2. 牆用 `wall(x, y, w, h)`（厚度 `T = 0.3`），重型實體用 `block`，輕型用 `rubble`。
3. 部署方向為「上下」的地圖，部署區深 3"；「左右」為 6"。
4. 目標標記記錄中心座標；控制範圍沿用程式中的 `CONTROL`。
5. 完成後與原圖並排截圖核對，再提交。
